> **HAFT** (Hindi Adversarial Fact-Checking Testbed) is an empirical research suite studying the adversarial robustness of Automated Fact-Checking (AFC) systems in Devanagari Hindi.

---

## 📌 Repository Overview & Structure

```
├── Attack/                   # Main benchmark engine, runners, UI, and results
│   ├── attacks/              # 14 Rule-based attack implementations (Pure Python)
│   ├── llm_attacks/          # 8 LLM-based generative attack implementations
│   ├── output/               # Perturbed claims generated by rule-based attacks
│   ├── output_llm/           # Perturbed claims generated by LLM attacks
│   ├── results/full_run/     # Complete 22 per-attack ground truth CSVs & summary JSON
│   ├── sampled_dataset_1120.csv # Stratified 1,120 benchmark claims across 6 domains
│   ├── app.py                # 4-Tab Streamlit benchmark explorer & predictor
│   ├── server.py             # Zero-dependency Python HTTP server (Port 8501)
│   ├── index.html            # Standalone modern web dashboard
│   ├── CURRENT_SYSTEM.md     # System audit and component mapping
│   └── Project Files/        # Comprehensive research execution plans and notes
│
├── README.md                 # Project introduction and quick-start
└── .gitignore                # Safeguards for API secrets, caches, and binary documents
```

> **Note:** Raw external documents (PDFs, DOCX, XLSX spreadsheets) and intermediate API checkpoint caches (`.verify_cache/`) are managed locally and excluded from version control to maintain a lean, reproducible codebase. The complete evaluated outcomes are stored in `results/full_run/*.csv` and `sampled_dataset_1120.csv`.

## 📊 Completed Benchmark Summary (Frozen Ground Truth)

* **Claims Evaluated:** 1,120 stratified Hindi claims across 6 domains (571 SUP, 350 REF, 199 NEI).
* **Inter-Annotator Agreement:** 300 double-annotated rows, 96.7% agreement, Cohen's $\kappa = 0.946$.
* **Clean Baseline Accuracy:** **74.29%** (832/1,120 correct verifications; 288 baseline failures excluded from ASR).
* **Exhaustive Evaluation Scale:** 22 attacks $\times$ 1,120 claims = **24,640 attack instances** (+ 1,120 baseline = 25,760 total evaluations).
* **Phase B 5-LLM Comparison:** DeepSeek-V3 (**72.73% accuracy**) outperformed GPT-4o, Claude 3.5 Sonnet, and Kimi-k1.5 (**27.27%**).
* **Phase C Predictor Baseline:** 22-fold Leave-One-Out (LOO) few-shot in-context predictor achieved **86.36% accuracy** (19/22 correct).

## 🚀 Quick Start & Interactive Dashboard

To launch the local web interface and explore the ground truth knowledge base:

```bash
cd Attack
streamlit run app.py
```

Or using the zero-dependency standalone server:

```bash
cd Attack
python server.py
# Open http://localhost:8501 in your browser
```
